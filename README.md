# Douceurs à la Maison

J'aimerai créer un "site vitrine" pour une mini entreprise de service à la personne (qui fait à manger pour les personnes ou pour les fêtes) avec une partie pour les plats froids (buffet), et une partie pour les plats chauds (type recette de grand-mère). J'aimerai que l'esthétisme du site reste dans les couleurs #e4d0bb et #94806c
